# 설계: 코드의 계획·설계 인용은 실재하는 파일을 가리킨다

- **계획**: 109 `citation-alive` (`docs/plan_citation-alive.md`)
- **트리거**: 파일 3개 이상(14파일) · 되돌리기 어려운 선택(표기 규약을 저장소 전체에 건다)
- **사용자에게 안 묻는다** — `design.md` 4절의 넷(사용자 데이터 · 공개 계약 · 의존성 · 보안 경계)에 없다.

## 결정

**갈래 A — 형태로 가르지 않는다.** 백틱 안의 `` `(plan|design)_….md` `` 는 **「실재하는 파일을
가리킨다」는 약속**이고, 검사는 그 약속만 잰다. 파일이 아닌 것(합성 픽스처 이름 · 과거 사례
산문)은 **`.md` 를 떼고 슬러그로** 적어 약속 밖으로 나간다. 토큰은 **아카이브 꼴까지 함께**
문다.

## 실측 (논증보다 먼저)

반복 650·651 탐침(워킹트리 무변경):

| 잰 것 | 값 |
|---|---|
| 코드의 백틱 `(plan\|design)_<슬러그>.md` | 13종 **28회** · 14파일 · **전부 결손** |
| 같은 자리의 아카이브 꼴 `*_history_<NNN>.md` | 8종 **18회** · **결손 0** |
| 후계자가 아카이브 하나로 되짚히는 종 | 13종 중 **9** (나머지 4종은 후보 2~9개) |
| 포인터가 아닌 자리 | **3** (픽스처 1 · 과거 사례 산문 2) |
| `docs/*.md` 안의 결손 토큰(범위 밖) | **44종** |
| **백틱 밖** 같은 꼴(반복 654 리뷰가 잰 것 · 범위 밖) | 69회 중 **65 결손** · 34종 (합성 픽스처 이름 8 을 빼면 실포인터 **57**) |

**이 표가 결정을 밀었다.** 저장소는 이미 **아카이브 이름으로 가리키는 쪽이 다수**다(18회가
그렇게 적혀 있고 하나도 안 썩었다). 새 규약을 발명하는 것이 아니라 **다수를 강제**하는 것이다.
아카이브 이름은 회전이 끝난 **불변 이름**이라 한 번 고치면 다시 안 썩는다.

## 대안 비교

**B — 해석 뿌리를 넓힌다** (루트 `README.md`·`docs/specs/`·`docs/e2e/<슬러그>/result.md` 도
뒤져 존재로 친다). **이 축에서는 무의미하다** — `plan_*`·`design_*` 는 `docs/` 에만 산다.
뿌리가 갈리는 것은 범위 밖으로 둔 `docs/*.md` 44종 쪽이고, 거기서 다시 판단한다.

**C — 검사가 후계자를 스스로 해석한다** (슬러그로 아카이브를 뒤져 있으면 통과). **기각.**
① 그러면 **아무도 인용을 안 고쳐도 초록**이라 재는 자가 문서를 안 고치는 자가 된다.
② 후보가 여럿인 4종(`plan_recrawl` 은 **9개**)에서 기계가 고르면 **틀린 문서를 가리키게**
만든다 — 끊긴 포인터보다 나쁘다(끊긴 것은 시끄럽고, 틀린 것은 조용하다).
③ 아카이브 전수를 읽어야 해 검사가 느려지고, 아카이브 본문 편집에 흔들린다.

**D — 코드를 안 고치고 검사만 둔다** (RED 를 「알려진 빚」으로 기록). **기각** — 이 저장소
최다 재발 계열이 바로 「적어만 두고 안 무는 것」이다.

## 계약

1. **대상**: `src`·`tests`·`e2e`·`scripts` 의 `.py`·`.sh`·`.js`. `docs/` 는 이 계획 밖이다.
2. **토큰**: 백틱으로 감싼 `(docs/)?(plan|design)_<이름>.md` — 슬러그 꼴과 아카이브 꼴을
   **한 정규식으로** 본다. 백틱 없는 이름·`.md` 없는 슬러그는 약속 밖이라 안 문다.
   **같은 백틱 안에 절·줄 표기를 붙인 꼴(`` `design_x.md ## 계약` ``)도 문다** — 반복 654
   리뷰가 그 꼴 한 자리를 실물에서 찾았고 **없는 파일을 가리킨 채 조용했다**. 관용구는
   절을 백틱 밖에 따로 적는 것이라 이 확장은 오탐을 안 늘린다(실측: 인용 46 → 48).
3. **판정**: `docs/<이름>` 이 실재하면 통과, 아니면 갭. 갭은 **파일:줄과 이름을 함께** 뱉는다.
4. **자기 참조를 푼다**: 패턴 픽스처의 이름은 **조립해서 만든다**(`"`plan_%s.md`" % …`) —
   리터럴로 박으면 실물 축이 자기 픽스처를 물어 **검사가 자기 때문에 영원히 빨갛다**.
5. **빈손 통과 금지**: 순회가 0회 돌면 실패한다(대상 디렉터리 하나라도 안 훑으면 갭).
6. 아카이브(`docs/*_history_*.md`)는 **읽지도 고치지도 않는다**.

## 되돌리기

검사 한 벌(`tests/test_docs.py`)과 주석 28줄뿐이라 `git revert` 로 원상복구된다. 제품 동작
`src/` **0줄** — `indexer.py`·`store.py` 는 주석만 바뀐다.

## 범위 밖 (digest 후보로도 남긴다)

- `docs/*.md` 안의 결손 인용 **44종** — 해석 뿌리가 넷으로 갈린다(루트 `README.md` ·
  `docs/specs/` · `docs/e2e/<슬러그>/result.md` · **저장소 밖 루프 룰**). 그중
  **`index.md` 가 23회 대는 `candidates.md` 는 저장소에 아예 없다.**
- **마감 절차가 인용을 안 고친다** — 검사는 «고치라»고 말할 뿐, 아카이브할 때 자동으로
  갱신하지 않는다. 절차 쪽 처방은 저장소 밖(`docs.md` 4절)이라 밤이 못 연다.
