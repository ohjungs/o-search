## 넘긴 것 — 리뷰 5 가 볼 것

1. **골드 표가 «지금 동작» 을 베낀 것이 아니라 «사람이 인용할 문단» 인가.** 여덟 행의 정답을
   내가 썼으니 **내가 검토자가 아니다.** 특히 «목록 항목이 진짜 답인 문서» 의 정답을
   `'김치찌개'`(4자)로 적은 것 — 다른 행에서는 4자짜리를 결함이라 부르면서다.
2. **`block` 인자가 색인 경로에 진짜로 안 닿는가.** 위 4,128건 밖의 반례를 찾는 자리다.
3. **동점 깨기가 만든 새 편향.** 길이를 선호하면 **긴 보일러플레이트**(사이드바·푸터를
   한 블록으로 담은 문서)가 이길 자리가 있는가.
4. **닫지 않은 축** — 내비 링크가 둘 이상이면 `<a>` 가 인라인이라 `'김치찌개된장찌개'` 로 붙어
   **점수로** 이긴다. «보일러플레이트와 인라인 연접» 은 다른 축이라 `digest` 후보로 넘겼다.
5. `e2e` 는 문단 경로 5종만 돌렸다. **20종 전수는 e2e phase 의 일이다.**
