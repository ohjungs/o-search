## 이 phase 가 새로 잰 것 하나

**맨몸으로 돌려도 `Ran/OK` 가 화면의 마지막이 아니다.** `unittest` 의 판정은
stderr(무버퍼)로 나가고 테스트의 `print()` 는 stdout(블록 버퍼)으로 나가서, 남은
버퍼가 `OK` **뒤에** 늦게 플러시된다(① 에서 `수집 0 페이지`·`1 문서 색인` 이 그
자리에 나왔다). 판정을 확인하려는 사람이 화면 **끝이 아니라 가운데**를 뒤져야 했다는
뜻이고, 그것이 「출력이 길다」를 서른 번 만든 물리적 원인이다. 완료 기준 A-2 가
그 줄을 **0줄**로 잰다. 천장도 적었다 — `-b` 는 **초록 실행에서만** 판정을 마지막
줄로 만든다(④ 에서 `FAILED` 뒤에도 늦은 플러시가 붙었다. 그건 봐야 할 것이라 무해하다).
