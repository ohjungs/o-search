# e2e 결과 — url-normalize (018)

## 무엇을 사용자 관점으로 봤나

017 과 같은 자리에서 잰다 — 여기서 "사용자" 는 **크롤당하는 사이트**이고, 재는 것은
우리 로그가 아니라 **서버가 실제로 받은 요청**이다. 크롤러 내부 상태(`_seen` 크기,
`store.count()`)를 재면 "우리가 의도한 중복 제거" 를 재는 것이지 사이트가 겪은
중복 요청을 재는 것이 아니다.

계획이 연 문제는 한 문장이다 — **같은 문서인데 표기가 다르면 다른 문서 취급.**
017 이 "어느 서버인가" 를 한 칸으로 모은 뒤에도 `Frontier._seen` 과
`store.pages.url` 은 문자열 그대로를 열쇠로 썼다. 간격은 지켜지므로 윤리 위반은
아니지만, 같은 문서를 표기 수만큼 받고 표기 수만큼 저장하고 표기 수만큼 색인한다 —
크롤 예산과 색인 크기가 같은 비율로 샌다.

수단은 새 `e2e/url_normalize_e2e.py`. 진짜 소켓·진짜 HTTP·진짜 robots 파서·진짜
SQLite 가 돈다. 바깥 네트워크는 안 탄다.

**한 가지만 주입했다: 이름이 어느 포트로 가느냐** (017 과 같은 층 — hosts 파일이
하는 일이다). **갈린 표기도 전부 `PORTS` 에 등록한다** — 등록을 빼면 정규화를
지운 변이가 "연결 실패" 로 죽어서, 재려던 "두 번 받았다" 를 관찰할 수 없다.
같은 문서를 가리키는 표기는 **한 실서버**에, 대조군만 **다른 실서버**로 간다.

## `domain_key_e2e.py` 는 축을 바꿨다

018 이 017 의 e2e 를 깼다. 그 파일은 대소문자(`A.test`)와 기본 포트(`a.test:80`)로
표기를 갈랐는데, `urls.normalize` 가 **URL 이 태어나는 자리에서** 그 둘을 접는다 —
표기 셋이 링크 단계에서 하나가 되니 서버에 하나만 도착하고, 재려던 상황이 안
만들어졌다. **조용한 통과가 아니라 크게 실패했다**(실측: `세 표기가 다 도착하지
않았다: ['a.test']`). 017 이 심어 둔 "표본이 사라지면 죽는다" 가 제 일을 했다.

새 자는 **userinfo** 다. `normalize` 는 userinfo 를 보존하고(떼면 요청 내용이
바뀐다) `domain_key` 는 뗀다 — `http://u@a.test/p` 와 `http://a.test/p` 는
**다른 문서지만 같은 서버**다. 018 이 안 접는, 살아 있는 유일한 축이다.

**여전히 017 의 회귀 탐지기다** — 되돌리기 변이로 확인했다. 프런티어와 제출부가
날 `netloc` 을 쓰게 하면(`u@a.test` 와 `a.test` 로 칸이 갈린다) 재려던 그 단언에서
죽는다: `표기가 다르다고 2초 선언이 새어 나갔다 — 서버 수신 간격 ['0.001', '0.000']`.

```
OK 7.0s — 같은 서버 4회 도착(표기 ['a.test', 'bot@a.test', 'u@a.test'])
          간격 ['2.01', '2.01', '2.01'] · robots 1회 · 대조군(a.test:443) 간격 ['1.01', '1.00']
```

`robots.txt` **1회**가 같이 걸려 있다 — `robots._base` 도 `domain_key` 를 쓰므로
표기마다 받으면 여기서 죽는다.

## 한계 — 이 e2e 가 안 재는 것

**기존 DB 는 안 잰다.** 이 변경은 **새 DB 에서만 목적을 달성한다.** 018 이전에
정규화 안 된 열쇠로 저장된 행은 `pages.url` PK 에 그대로 남고, `store.has(정규화된
URL)` 이 그것을 못 찾아 같은 문서를 다시 받고 다시 저장한다(재현:
`upsert('http://A.com:80/p')` → `has('http://a.com/p')` **False** → `pages` 2행 ·
`docs` 2행 · 검색 결과 2건). 일회성 통합은 마이그레이션이라 **야간이 안 한다** —
`docs/digest.md ## 판단 필요` 와 계획서 4절에 올렸다. 사람 승인이 필요하다.

**점 세그먼트(`/a/../p`)는 안 접는다.** 상대 링크는 `urljoin` 이 이미 접고 절대
href 는 안 접는데, 실물에서 중복원으로 잰 적이 없어 안 했다(digest `[4]`).

**URL 에 실린 자격증명**이 `pages.url` PK 이자 검색 결과 링크가 되는 것도 이 계획이
안 닫았다 — 보안 경계라 줄 수와 무관하게 야간 자동 적용 금지다(digest `## 판단 필요`).
