## 않을 것

- **이름 생성 쪽을 고치지 않는다.** 후보가 처방 둘을 적고 「후자가 옳다」로 못박았다 —
  생성은 손이 하고, 손을 고치는 자(`%02d`)는 밤마다 다른 손을 못 막는다. **신고하는 쪽**을 세운다.
- **`pin_rot_gap` 안에서 패딩 없는 이름을 「고쳐 읽지」 않는다.** `10-5` 를 `10-05` 로 관용하면
  자가 틀린 이름 위에서 **초록으로** 돌아 사람이 그 꼴을 계속 쓴다. 틀린 이름은 **빨강**이다.
- **접미사 허용을 좁히지 않는다.** 같은 날 두 벌인 날이 넷이라(`09-09` 2 · `09-10` 2 ·
  `09-12` 3 · `09-14` 2) `^night_YYYY-MM-DD` **접두** 판정이 맞다 — 거기까지만 못박는다.
- **날짜의 «값» 을 검사하지 않는다.** `night_2026-13-45.md` 같은 불가능한 날짜는 범위 밖이다
  (실물 0건 · `datetime` 을 들이면 `night_reports` 의 「사전순이 곧 날짜순」 설계가 흔들린다).
- **`signal_row_gap` 의 최신-하나 꼴 검사를 지우지 않는다.** 새 자가 그것을 **포함**하지만,
  둘은 메시지가 다르고(`pin_rot_gap` 집계 경고 vs 신호 줄 부재) 지우는 것은 직교 편집이다.
  **중복은 적어 두고 남긴다** — 리뷰가 값을 재면 그때 접는다.
