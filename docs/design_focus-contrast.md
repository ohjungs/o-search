`NONTEXT_PAIRS = [("--focus", "--bg-page")]` 를 더하고, 커버리지 강제에서

## 갈림길 A — 임계값 (출발점: 최소 vs 정공법)

| | A1 최소 — `MIN_CONTRAST` 4.5 재사용 | **A2 정공법 — `MIN_CONTRAST_NONTEXT` 3.0** ← |
|---|---|---|
| 더 적게 쓰나 | 상수 **0개** 추가 | 상수 1개 추가 (되돌리기는 둘 다 커밋 하나) |
| 기존과 맞나 | △ 상수마다 출처를 붙이는 관례에서 텍스트 기준을 비텍스트에 붙이면 **출처가 거짓**이 된다 | ○ `JS_BUDGET`·`MIN_CONTRAST` 처럼 출처 한 줄을 단다 |
| 다음이 편한가 | **×** 표준에도 사양에도 없는 요구라 비텍스트 토큰마다 **오탐** | ○ 새 토큰이 옳은 자로 재진다 |

**버린 이유(A1)**: 사양은 "**텍스트** 대비 4.5:1" 이다. 오탐을 내는 검사는 결국
**제외 목록으로 도망친다** — 이번에 뒤집는 그 문을 스스로 여는 셈이고, 상수 하나
아끼자고 검사기의 신뢰를 판다.

## 갈림길 B — 색값 (A 를 3.0 으로 고르면 후보가 셋으로 준다)

**`#ea580c`.** 팔레트에서 **한 칸**(orange-500 → 600)이고, 3:1 을 19% 여유로 넘으며,
버튼(orange-700)보다 밝아 버튼 위에서도 링이 남는다.

- **`#c2410c` 버림** — 수치(5.18)는 통과다. 버린 이유는 수치가 아니라 **버튼색과 같다**는

  테두리가 하나 더 생겼다" 로 보인다. 포커스 링의 일은 대비가 아니라 **어디 있는지**다.

## 갈림길 C — 커버리지 강제의 모양 (되돌리기 우선 출발점 포함)

| | C1 접두어 확장 `("--fg-", "--focus")` | **C2 전 토큰 + 명시 제외** ← | C3 값이 `#rrggbb` 인 토큰만 |
|---|---|---|---|
| 한 일 | 한 글자 수정 | 두 줄 교체 + 상수 1개 | 판별 함수 하나 |
| 막는 것 | `--focus` **하나** | 이름이 무엇이든 전부 | 색으로 보이는 것 |
| 뒷문 | **다음 `--ring`·`--accent` 가 또 샌다** | 코드에 이름과 사유를 적어야 열린다 | **`rgb()`·`color-mix()` 로 적으면 샌다** |

**버린 이유(C1·C3)**: 이번 구멍이 계획 13 이 닫은 눈먼 자리의 **형제**인 이유가 바로
"허용 목록을 이름으로 적었다" 는 것이다 — C1 은 형제를 하나 더 낳는다(그리고 이 구멍은
211 반복 동안 아무도 못 봤다). C3 는 **파서가 `#rrggbb` 만 해석한다는 사실이 그대로
뒷문**이 되므로 같은 실패를 형태만 바꾼 것이다.

## 가정 — 틀리면 이 설계가 무너진다

1. **링의 이웃은 언제나 `--bg-page` 다** — `outline-offset:2px` 의 틈이 페이지 배경이고
   라이트에서는 `--bg-input` 도 `#ffffff` 다(실측). → 둘이 갈라지는 날 **짝을 하나 더 적는다.**
2. **선언 토큰 11개가 전부 색이다.** 색 아닌 토큰이 생기면 `NO_PAIR` 에 사유를 적어야
   통과한다 — 마찰이 아니라 **의도**이고, C3 를 버린 이유가 그것이다.
3. `token_maps` 가 두 맵을 다 준다(다크 블록이 없으면 이미 `ValueError`). **파서는 0줄.**

## 계약 — 개발이 이대로 쓴다

```python
MIN_CONTRAST_NONTEXT = 3.0   # WCAG 2.1 SC 1.4.11 — 비텍스트 UI 지시자. concept.md 는 텍스트만 적었다
NONTEXT_PAIRS = [("--focus", "--bg-page")]   # outline-offset:2px 라 링의 이웃은 언제나 페이지 배경
NO_PAIR = {"--line": "순수 장식 테두리(구분선·입력창 테두리) — UI 지시자가 아니다"}
```

- **커버리지 강제**(`check_contrast` 안, `startswith` 두 줄을 대체):
  `paired = {t for pair in PAIRS + NONTEXT_PAIRS for t in pair}` ·
  `missing = (set(light) | set(dark)) - paired - set(NO_PAIR)` ·
  메시지 `"짝도 제외도 없는 색 토큰: %s"` → **`unmeasurable`(rc 2)**. `fail`(rc 1) 이 아니다.
  제외는 dict 라 **사유를 안 적으면 문법이 안 된다** — 그것이 이 문에 이름이 걸리는 방식이다.
- **재는 루프**: 겹을 하나만 더 돈다 —
  `for pairs, floor in ((PAIRS, MIN_CONTRAST), (NONTEXT_PAIRS, MIN_CONTRAST_NONTEXT))`.
  두 자가 한 절에 섞이므로 **출력 행에 기준값을 적는다**(화면만 보고 어느 자인지 알아야 한다).
  `fail` 문구도 그 행의 `floor` 를 쓴다.
- **`serve.py`**: 라이트 `--focus:#f97316` → `#ea580c` **한 값**. 다크 `#fdba74` 는 0줄.
  CSS 위 규약 주석의 *"`--fg-` 토큰을 새로 만들면 `PAIRS` 에도 짝을 적어라"* 한 문장을
  *"색 토큰을 새로 만들면 `PAIRS`/`NONTEXT_PAIRS` 에 짝을 적거나 `NO_PAIR` 에 사유를 적어라"*
  로 바꾼다. 접두어를 말하는 표현은 남기지 않는다 — 강제가 접두어를 안 본다.
- **화면 문구**: 모듈 docstring 의 3번 축 줄과 `[3]` 절 머리에 비텍스트를 적는다.
- **`README.md ## 품질 기준`**: 명암비 행을 `텍스트 ≥ 4.5:1 · 비텍스트 ≥ 3:1` 로.
  한 행이고, `test_readme` 가 붙드는 두 숫자(469·19)는 **안 건드린다**.
- **단위 테스트는 0건 추가**(계획 5절 그대로 — 색값을 단위에 적으면 검사기가 값을 따로 드는
  것과 같아진다). 단위는 **469건 무변**이어야 한다.

## 범위 밖

- **`--line` 을 UI 컴포넌트 경계로 볼지**(1.34:1) — 그렇게 보면 3:1 이 붙지만, 그 판단은
  이번 근거(사양 3축 · 포커스 링 실측)에 없다. 제외 상수의 **사유 문자열이 그때까지의
  기록**이고, `digest` 후보로 넘기는 것은 **DONE 반복이 한다** — 지금 항목을 더하면 이번
  반복이 열린 항목 48·200줄 상한을 근거 없이 흔든다.
- **다크 테마의 어떤 값도** · **`outline` 두께·offset 대안**(색 하나로 넘겼으므로 필요 없다) ·
  **`design_check` 의 나머지 3축** · 헤드리스 브라우저.
