## 1. 관통 — 저장소 밖 사본에서 5막

`git archive HEAD | tar -x` 로 `mktemp -d` 사본을 만들고, 막마다
`PYTHONDONTWRITEBYTECODE=1 PYTHONPYCACHEPREFIX=$(mktemp -d)` 를 새로 준다.
**워킹트리 무변경** — 편집은 전부 사본에서 했고 저장소는 읽기만 했다.

```
PYTHONDONTWRITEBYTECODE=1 PYTHONPYCACHEPREFIX=$(mktemp -d) PYTHONPATH=src \
  python3 -m unittest discover -b -s tests
```
