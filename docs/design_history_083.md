# 설계: 표기 형태를 안 보고 실재만 잰다

- **계획**: 110 `bare-citation` (`docs/plan_bare-citation.md`)
- **트리거**: **대안이 갈림** — 합성 픽스처를 오탐에서 가르는 갈래가 넷 · 파일 27개
- **작성**: 2026-09-28 (반복 658)

## 결정

**A** — `citation_sites()` 에서 **백틱 조건을 없앤다**. 자는 형태를 안 보고 토큰만 센다.
합성 픽스처는 **자에 예외를 만들지 않고 픽스처 쪽을 조립 꼴로 고쳐** 눈에서 뺀다
(계획 109 `CitationAlivePatternTest` 가 이미 쓴 수법 — `NAME = "%s_%s.md"`).

## 실측 (논증보다 먼저)

착수 탐침(반복 657)과 이 설계의 탐침(반복 658)을 같은 자로 쟀다.

```
코드 인용 117회 = 백틱 안 48 (결손 0 · 계획 109 가 고쳤다) + 백틱 밖 69 (결손 65)
결손 65 = tests/test_docs.py 합성 픽스처 9 + 실포인터 56 (28종 · 27파일)
```

**가장 위험한 가정을 깨봤다 — 「56자리의 후계자를 찾을 수 있다」.** 절반만 참이다.
아카이브 머리의 **슬러그·브랜치 필드**(`- **슬러그**:` / `- **브랜치**:`)만 보는 기계적 규칙은
**22종 중 6종**밖에 못 짚는다. 나머지는 머리 형식이 다르다 — 문장형 「슬러그 X · 브랜치 loop/X」
(011) · `- slug:` 꼴 (009) · 제목 줄 「# 계획: X — …」 (011·012). 그리고 느슨하게 재면
**거의 모든 종이 후보 둘**로 나오는데, 둘째는 언제나 「기점 loop/X」 로 **갈라져 나온
다음 계획**이다. 즉 후계자는 유일하고, **유일성을 주는 것은 「자기 브랜치로 X 를 선언했나」**다.
가정은 살았고, 대신 **해석 규칙이 계약으로 들어간다**(아래) — sed 로는 못 한다.

## 대안 비교

| | A. 픽스처를 조립한다 | B. 무시 주석 | C. 파일 예외 명부 |
|---|---|---|---|
| 되돌리기 | 커밋 revert | 커밋 revert | 한 줄 revert |
| 자에 드는 코드 | **0줄** (조건 삭제라 오히려 준다) | 규칙 하나 + 주석 9개 | 상수 하나 |
| 기존과 일치 | **높다** — 109 가 같은 수법을 썼다 | 낮다 | 낮다 |
| 다음이 편한가 | 픽스처를 리터럴로 쓰면 빨개진다(의도된 마찰) | **탈출구다** | **자기 눈을 가린다** |

**선택: A** — C 는 치명적이다. `tests/test_docs.py` 는 픽스처만 든 파일이 아니라 **이 저장소
문서 규칙의 본체**이고, 계획 109 가 고친 실포인터 3자리가 바로 거기 있었다. 파일째 면제하면
**자가 제 집을 안 본다.** B 는 109 리뷰 [R109-1] 이 닫은 탈출구를 다시 여는 것이다 — 주석
한 줄로 진짜 결손도 숨길 수 있고, 밤에는 그 한 줄을 아무도 못 본다. A 의 비용은 「픽스처를
새로 쓰는 사람이 조립 꼴을 몰라 한 번 빨개지는 것」뿐이고, 그 값은 실패 메시지가 치른다.

## 계약

```
citation_sites(root) 는 백틱 표기를 보지 않는다 — (plan|design)_<슬러그>.md 토큰을
ALIVE_DIRS × ALIVE_SUFFIXES 전부에서 모은다. 실물 하한 ALIVE_CITATION_FLOOR 는 100.
citation_alive_gap(sites, docs) 의 계약은 그대로다 — 없는 문서를 「파일:줄 이름」으로 댄다.

합성 픽스처는 한 리터럴에 토큰을 담지 않는다 (예: NAME % ("plan", "x")).
실패 메시지가 이 문장을 그대로 들고 있어야 한다 — 다음 사람이 고칠 방법을 거기서 읽는다.
```

**후계자 해석 규칙(스텝 2)** — 위에서부터 멈춘다. ① 머리에 `슬러그`/`slug` 로 X 를 선언한
아카이브 ② 제목 줄이 `# 계획: X —` 인 것 ③ **자기 브랜치**가 `loop/X` 인 것 — 「기점 loop/X」
는 **후보가 아니다**(갈라져 나온 다음 계획이다). 셋 다 없으면 포인터를 버리고 `.md` 를 떼
슬러그로 남긴다(109 선례). 설계 인용은 계획을 먼저 짚고 그 번호대의 `design_history_*` 를 읽어 고른다.

## 되돌리기

자는 조건 한 줄이라 커밋 revert 로 이전 동작(백틱 안만)으로 돌아간다. 픽스처 조립과
27파일의 이름 정정은 **주석·문자열뿐이라 제품 동작이 없다** — 되돌릴 이유가 생겨도 위험이 없다.
