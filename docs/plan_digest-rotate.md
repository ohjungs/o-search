## 2. 근거

- **출처: 집안일(상한 초과).** `docs/status.md:72-73` 과 `docs/digest.md:14` 의 상한
  규칙. discover 순위표에는 없는 출처이므로, 순위 1~8 에서 나올 것이 없다는 것을
  **먼저 실측하고** 골랐다(3절 탐침 A).
- **사용자 가치가 큰 후보를 일부러 안 골랐다.** 열린 후보 중 값이 가장 큰
  `docs/digest.md:178` 의 `[7]`(페이지 넘김에 중복 1건·누락 1건, 계획 37 탐색이 실측)은
  그 항목 자신이 **"루프가 열 계획이 아니라 사람이 정할 갈림길이다"** 라고 적었다 —
  `?page=N` 공개 API 를 커서로 바꾸는 갈림길이라 승인 없이 못 연다. `[8]` 토크나이저
  항목은 계획 10 이 대부분 닫았다(미검출 5 → 1, `docs/digest.md:27`).
- **그래서 이것이 임계경로다.** 탐색이 매번 읽는 파일이 상한을 36% 넘겼고, 그 안의
  항목 하나가 이미 닫혔는데 열린 것으로 보여 **이번 탐색을 실제로 오염시켰다.**

## 4. 스텝

**스텝이 2개인 이유:** 고칠 파일이 `docs/digest.md` 하나이고 할 일이 "깨진 것 고치기" 와
"넘친 것 줄이기" 둘뿐이다. 더 쪼개면 없는 일을 만드는 것이다.

### 스텝 1 — 손상 복구: H1 을 되돌리고, 닫힌 항목을 닫힌 것으로 표시한다

의존: 없음
건드릴 파일: `docs/digest.md`

- `docs/digest.md:1-2` 두 줄을 지우고, 첫 줄을 `# 아카이브 요약` 한 줄로 되돌린다.
  (`git show 6d3d075:docs/digest.md | head -3` 이 원래 모양이다.)
- 지운 1줄의 닫힘 문구(`~~[5]~~ **닫혔다 — `url-normalize`(018), 2026-08-27.** …`)를
  `docs/digest.md:135` 의 `- [5] **호스트 대소문자를 정규화하지 않는다**` 항목으로
  옮긴다. 그 항목을 `- ~~[5]~~ **닫혔다 — …**` 로 바꾸고, 지금 본문은 이 파일이 다른
  닫힘 항목에 쓰는 형식 그대로 `  - [원문] [5] **호스트 대소문자를 …** …` 하위줄로 내린다.

완료 기준 (전부 실행해서 확인한다):
- `head -1 docs/digest.md` → `# 아카이브 요약`
- `grep -c '^- \[' docs/digest.md` → **47** (오늘 48)
- `grep -c '^  - \[원문\]' docs/digest.md` → 오늘 값 **+1**
- `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m unittest discover -s tests` → **456건 OK**

### 스텝 2 — 회전: 닫힌 것과 가장 오래된 완료를 지운다

의존: **스텝 1** — 스텝 1 이 `docs/digest.md:135` 에 만든 취소선 항목이 이 스텝의 삭제
대상에 들어간다. 순서를 바꾸면 그 항목이 열린 채로 남는다.
건드릴 파일: `docs/digest.md`

- `## 다음 계획 후보` · `## 다음 계획 후보 (테스트 phase 갭, 8점 미만)` · `## 판단 필요`
  세 섹션에서 `- ~~` 로 시작하는 최상위 항목과, 바로 뒤따르는 `  - [원문]` 하위줄을 지운다.
- `## 반복 실패` 섹션은 **손대지 않는다** — 머리말 규칙이 "보류·반복실패는 남긴다" 이다.
  그 안의 닫힌 CLI 항목(`docs/digest.md:82`)도 남긴다.
- `## 완료` 에서 `- 2026-08-25` · `- 2026-08-26` 으로 시작하는 **7줄**을 지운다.

완료 기준:
- `wc -l docs/digest.md` → **≤ 200** (탐침 C 예상값 **187**)
- `grep -c '^- \[' docs/digest.md` → **47** — 열린 항목이 하나도 안 지워졌다
- `grep -c '^- ~~' docs/digest.md` → **1** — 반복 실패 섹션의 닫힌 CLI 항목 하나만 남는다
- `awk '/^## 반복 실패/,/^## 다음 계획 후보$/' docs/digest.md | grep -c '^- '` → **3**
- 단위 **456건 OK**

## 6. 설계 생략

문서 한 파일에서 닫힌 항목을 지우고 깨진 머리 두 줄을 되돌리는 일이다. 모듈 경계·데이터
구조·되돌리기 어려움 어디에도 안 걸린다. **대안이 하나뿐이다** — 지우는 방식은
`docs/digest.md:14` 머리말이 이미 정해 뒀고(오래된 완료부터, 보류·반복실패는 남긴다),
아카이브 파일을 새로 만드는 안은 그 규칙이 배제한다(원본은 `history_*.md` 에 있다).
