# 설계: 병합 게이트가 모집단 0 을 초록으로 통과시키지 않는다

- **계획**: `plan_merge-verdict.md`
- **트리거**: **대안이 갈림** — 덮는 범위와 「판정의 단일 출처」가 반대로 기운다
- **작성**: 2026-09-28 (반복 644)

## 결정

**A** — `merge-to-main.sh:23` 의 기본 `TEST_CMD` 안에서, 환경 변수 배정 **뒤에**
`scripts/verdict.sh` 를 끼운다. 판정은 계속 래퍼 하나가 내린다.

## 실측 (논증보다 먼저)

기본값 꼴 그대로 `eval` 아래서 두 번 쟀다 — 36행이 `eval` 이라 그 형태로 재야 한다.

```
eval "PYTHONDONTWRITEBYTECODE=1 PYTHONPYCACHEPREFIX=$(mktemp -d) PYTHONPATH=src \
      scripts/verdict.sh python3 -m unittest discover -b -s tests"
  → Ran 831 tests … OK        ── Ran 831 tests in 24.681s OK rc=0
동일 꼴에서 `-s scripts` (모집단 0)
  → Ran 0 tests … OK          ── Ran 0 tests in 0.000s 모집단 0 rc=2
```

세 가지가 확인됐다. ① 환경 변수를 **앞**에 둔 형태는 `eval` 을 거쳐도 `rc=127` 이 아니다
(배정이 래퍼 환경에 들어가고 자식이 물려받는다). ② `$(mktemp -d)` 도 `eval` 안에서 그대로
확장된다. ③ 0건에서 `rc=2` 이므로 39행의 `[ $trc -eq 0 ]` 이 **손대지 않은 채로** 병합을 막는다.

덧붙은 이득 — 37행이 `echo "$OUT" | tail -3` 인데 래퍼의 판정이 **마지막 줄**이라
그 `tail` 이 판정을 자르지 않는다. 래퍼가 원래 노린 손이 바로 이것이다.

## 대안 비교

| | A. 기본값 안에 래퍼 | C. 39행에서 `OUT` 직접 검사 |
|---|---|---|
| 되돌리기 | 한 줄 revert | 한 줄 revert |
| 코드량 | **한 줄** (래퍼 재사용) | 한 줄 + 판정 규칙 복제 |
| 기존과 일치 | **높다** — 저장소의 모든 검증이 이미 이 래퍼를 탄다 | 낮다 — 같은 판정을 두 곳이 내린다 |
| 덮는 범위 | 기본 경로 | 기본 + `MERGE_TEST_CMD` 주입 |
| 다음이 편한가 | **높다** — 래퍼가 기준을 고치면 문도 따라온다 | 낮다 — 고칠 곳이 둘, 어긋나면 조용하다 |

**선택: A** — C 가 범위 한 칸에서 이기지만, 이기는 그 칸이 **테스트 주입 구멍**이고
(`merge-to-main.sh:14` 가 그렇게 선언한다) 지는 칸이 **「모집단 0 이 무엇인가」의 단일
출처**다. 계획 107 이 그 정의를 `verdict.sh:78-87` 한 곳에 모은 직후에 둘로 쪼개는 것은
그 계획을 되돌리는 것과 같다. **두 자가 같은 것을 판정하면 언젠가 어긋나고, 어긋남은
조용하다** — 이 저장소가 가장 자주 당한 실패 모양이다.

**버린 이유**
- **C** — 위. 덧붙여, 주입까지 덮는다는 이득이 **실전 경로가 아니다**: 주입은 테스트가
  빨간 갈래를 밟으려고 쓰는 구멍이고, 사람이 병합할 때 쓰는 것은 기본값이다.

## 계약

```
merge-to-main.sh:23 의 기본 TEST_CMD 는 `scripts/verdict.sh` 를 «환경 변수 뒤 ·
감쌀 명령 앞» 에 포함한다. 다른 행은 안 고친다 — 36·39행은 그대로다.

  모집단 0  → 래퍼가 rc=2  → 39행이 「전수 RED — 푸시 안 함」, 원격 main 불변
  전수 초록 → rc=0         → 40행이 push
  MERGE_TEST_CMD 로 갈아끼우면 래퍼를 안 탄다 (의도된 구멍 · 계획서 3절)
```

**래퍼 경로는 상대 경로다** — 전수는 `$WT`(main 의 worktree) 안에서 도는데
`scripts/verdict.sh` 가 거기에도 커밋돼 있으므로 풀린다. 절대 경로를 쓰지 않는 이유는,
쓰면 실행한 사람의 트리를 가리켜 **병합 결과가 아닌 코드로 재게** 되기 때문이다.

## 되돌리기

23행 한 줄이라 그 커밋만 revert 하면 이전 동작이다. 중간 상태가 없다.
`MERGE_TEST_CMD` 를 주면 래퍼를 통째로 우회할 수 있어 **막혔을 때 손이 있다.**
