## 8. 남기는 것 — 다음 세션이 이어받을 것

1. **괄호 한 겹 안의 결합자는 여전히 거짓 초록이다** — `:is(a:focus-visible > .hint)` 는
   링을 `.hint` 에 그리는데 통과한다(리뷰 1 실측). 고장이 아니라 **적힌 천장**이다:
   `_top_level` docstring 의 `ponytail:` 절 + `digest [5]`. 여는 조건은 이웃 후보들과
   같다 — «제품 CSS 에 괄호 있는 셀렉터가 처음 생길 때». 오늘 제품 CSS 에 괄호는 **0곳**이라
   3.56:1 은 참이다.
2. **안 닫힌 `(`** 와 **문자열 안 홀괄호의 순서 의존** 둘은 테스트 phase 가 8점 미만으로
   `digest` 에 등재했다. 전자는 깨진 CSS 라 제품에 실재 불가, 후자는 무해.
3. **괄호 두 겹 중첩**(`:not(:is(:where(:focus-visible)))`)은 `INDIRECT_RE` 의 알려진
   천장이고 계획 49 부터 `digest [4]` 다. 설계서 6절의 «CSS 파서를 안 만든다» 안쪽이다.
4. **`main` 으로 보내는 PR 은 사람 몫이다** — `origin/main` 은 `687a159`(계획 47)까지만
   받아 **PR #7 이 OPEN·미병합**이고 계획 48~52 가 그 뒤에 쌓여 있다. 무인 모드는
   PR 을 열지도 병합하지도 않았다(이 반복도 무접촉).
