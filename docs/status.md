### [기록만] — digest 로 넘긴다

- **digest `[5]` 는 절반만 닫혔다**(실측했다). "`sleep=lambda s: None` 공회전 91만 회는

  갈래**다: `wait_fn = sleep if stop is None else stop.wait`. `stop` 을 주면 공회전 **0회**
  (주입 `sleep` 호출 0 · CPU **0.00초**), `stop=None` 이면 **93만 회 그대로**(CPU 1.00초).
  `main()` 이 항상 `stop` 을 넘기므로 **실사용 경로는 닫혔다.** digest 갱신함.
- **`--deadline` 만료는 여전히 `stop` 을 안 쓴다** — 예산이 다해도 워커의 재시도 잠은
  안 접혀 꼬리가 실측 69.57초까지 남는다. 계획 6절이 "`--deadline` 과의 통합"을 **하지 않을
  것으로 이미 정했고**, 이제는 `main()` 이 예산 만료 시 `stop.set()` 하는 몇 줄이 전부라
  값이 싸졌다. digest 후보.
- **e2e 시간 여유가 얇다** — 시나리오 1 은 소켓 10초에 상한 12.0초(여유 2초), 시나리오 2 는
