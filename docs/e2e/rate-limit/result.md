# e2e 결과 — 계획 79 `rate-limit`

## 1. 무엇을 걸었나

공개 API 두 경로(`/search`·`/passages`)에 **IP 당 분당 60회**. 숫자도 방식도 사양이
줬다(`docs/specs/concept.md` 「사람이 정할 것」 1 — 로그인이 없으니 IP 가 유일한 손잡이).
비어 있던 것은 착수 시점뿐이었다.

전수 **685 OK rc 0** · HTTP e2e 5종 rc 0 · 측정 하네스 4종 rc 0.

## 2. 실제 HTTP 로 확인한 다섯

`RateLimitWiringTest` 가 진짜 서버를 띄워 잰다 — **리미터 단위 테스트와 다른 질문**이다.
클래스를 만들어 두고 배선을 잊으면 단위 5건이 초록인 채로 아무것도 안 막는다
(`rules/review.md` 패스 A 의 *"실제로 실행되는 경로가 있나"*).

| 단언 | 결과 |
|---|---|
| 한도 넘기면 **429** + `Retry-After: 60` | 통과 |
| 예산은 **두 JSON 경로가 함께** 쓴다 | 통과 |
| **없는 경로(404)는 예산을 안 먹는다** | 통과 |
| **화면(`/`)은 제한 밖**이고 API 예산도 안 먹는다 | 통과 |
| `rate_limit=None` 은 **무제한**(전면 차단 아님) | 통과 |

## 3. 설계에서 갈린 자리 넷

**① 슬라이딩 창, 고정 창 아님.** 고정 창은 경계에서 2배가 통과한다 — 59초에 60회,
61초에 또 60회면 2초 사이 120회다. 값은 IP 당 `deque` 하나뿐이라 안 아낀다.

**② 락은 선택이 아니다.** 서버가 `ThreadingHTTPServer` 라 카운터는 공유 상태다.
`rules/dev.md` 6-1절이 말하는 「테스트 초록·리뷰 통과 뒤 부하에서만 드러나는」 종류라,
**계약을 테스트로 먼저 고정했다** — 스레드 8개가 동시에 200회를 쏴도 통과는 정확히 50.

**③ `time.monotonic`.** 벽시계는 NTP 보정으로 뒤로 갈 수 있고, 뒤로 가면 창이 늘어나
제한이 **조용히 풀린다.**

**④ 거절은 창에 안 넣는다.** 넣으면 두드릴수록 창이 안 비어 분당 60회가 아니라
**사실상 영구 차단**이 된다. 그건 다른 정책이라 사양을 고친 뒤에 할 일이다.

## 4. 제한이 측정 하네스를 죽였다 — 실측이 잡았다

`passage_eval` 이 **429 를 받아 「잴 수 없다」로 죽었다.** 질의 40개 × 5회 = 200회라
분당 60회를 당연히 넘는다. **제한이 재는 대상을 검색 지연에서 리미터로 바꿔 버린 것**이다.

처방은 `rate_limit=None`(무제한) 갈래이고, `perf_search`·`passage_eval`·`design_check`
셋이 그것을 쓴다. **매직 `0` 이 아니라 `None` 인 이유**는 `limit=0` 이 「한 번도 허용
안 함」으로도 읽히기 때문이다 — 무제한과 전면 차단을 같은 값에 태우면 언젠가 뒤집힌다.
그 뒤집힘을 `test_none_means_unlimited_not_blocked` 가 못박는다.

## 5. 오늘은 안 막는다 — 그래도 넣는 이유

서버는 `127.0.0.1` 에만 바인드한다(`serve.py`). **그래서 지금은 외부에서 닿지 못하고,
제한이 오늘 막는 것은 없다.** 그럼에도 넣는 이유는 컨셉이 「누구나 브라우저로 접속하는
공개 웹 검색엔진」이고, 노출되는 날 **제일 먼저 필요한 것이 이것**이기 때문이다.
노출과 제한을 같은 날 하면 그날 급해서 대충 한다.

**바인드 주소는 이 계획에서 안 건드린다** — 공개 노출은 배포 결정이라 별건이다.

## 6. 안 한 것

- **경로별 다른 한도.** `/passages`(p95 138ms)가 `/search`(16ms)의 8배로 비싼 것은
  사실이지만 사양이 준 숫자는 하나다. 쪼개려면 재고 사양을 고친 뒤에 한다.
- **`X-Forwarded-For` 신뢰.** 위조 가능하고 지금 앞단에 프록시가 없다. 믿을 앞단이
  생기는 날 그 신뢰 경계를 따로 판단한다.
- **영속화.** 재시작하면 창이 비는 것이 맞다 — 컨셉 2단계까지 단일 머신이다.
