## 시나리오

### ① 시작 디렉터리를 빠뜨린 전수 — 덫이 사라졌다

`PYTHONPATH=src python3 -m unittest discover -b` (시작 디렉터리 없음, 맨몸)

```
Ran 831 tests in 22.126s
OK                                   ← rc 0
```

**831건이 돈다.** 계획서가 문제로 든 `Ran 0 tests / OK / rc=0` 이 **안 나온다.**

**시나리오 문면과 실물이 갈렸고, 문면을 고쳤다 — 자기수정 ④.** 계획서 6절 1번은
「→ **초록이 안 나온다**」였는데 실물은 **초록이다**(831건 · `rc=0`). 낮춘 것이 아니라
**설계가 이미 문면을 앞질러 있었다**: 설계 가정 1 이 「시작 디렉터리를 빠뜨린 맨몸 전수가
0건이 아니라 826건을 돈다」를 **반복 634 에 실측으로 못박았고**, 그 값이 곧 갈림길 B 를
고른 이유다. 즉 문면의 「초록이 안 나온다」는 **갈림길 A(래퍼만) 에서만 참**이고 설계가
버린 갈래다 — 6절이 설계 결정 뒤에 동기화되지 않은 것이다. 이 계획이 지켜야 하는 것은
제목(**「0건 전수는 초록이 아니다」**)이고, 0건 자체가 안 생기면 그 명제는 공허하게 참이
아니라 **원인 쪽에서 참**이다. 그래서 「0건 초록이 안 나온다」로 고쳐 적고, 고친 문면이
공허하지 않다는 것은 아래 ⑤ **음성 대조**가 받친다.

### ③ 래퍼를 통과한 0건 — `| tail -1` 로 봐도 초록이 아니다

0건으로 끝나는 길을 **`-s scripts`**(테스트가 없는 디렉터리)로 냈다. 오늘의 덫은 ①이
치웠으므로, 래퍼 층은 **덫 밖의 0건 길**로 재는 것이 맞다(설계 「범위 밖」이 지목한 갈래).

| 손 | 결과 |
|---|---|
| 전문 | `── Ran 0 tests in 0.000s 모집단 0 rc=2` · 쉘 `rc=2` |
| `\| tail -1` | `── Ran 0 tests in 0.000s 모집단 0 rc=2` |
| `\| tail -1 \| grep -c OK` | **`0`** |

**계약 ③ 이 실물에서 산다.** 러너 원문은 여전히 `OK` 를 찍는데(위 전문의 넷째 줄)
마지막 줄에는 그 낱말이 없다. 반복 639 리뷰가 잰 `grep -c OK` → **1** 이 이제 **0** 이다.

### ⑤ 음성 대조 — 덫을 되살려 두 층을 따로 쟀다

**①이 「애초에 깨진 적 없는 것을 잰 것」이 아님을 여기서 받는다.** `git clone --local`
사본 `/tmp/zp107` 에서 **`tests/__init__.py` 만 지우고** 같은 명령을 쳤다.

| 사본에서 친 것 | 결과 |
|---|---|
| 맨몸 `discover -b` (시작 디렉터리 없음) | `Ran 0 tests in 0.000s` · `OK` · **`rc=0`** ← **덫이 되살아났다** |
| **래퍼로** 같은 명령 | `── Ran 0 tests in 0.000s 모집단 0 rc=2` · **`rc=2`** |
| 위를 `\| tail -1 \| grep -c OK` | **`0`** |

**첫 줄이 계획서 1절의 사고 현장이고**(digest 서른일곱째의 실물), 파일 하나를 지운 것만으로
그대로 돌아온다 — `tests/__init__.py` 의 주석이 「지우지 마시라」로 시작하는 이유가 측정됐다.
**둘째 줄이 설계가 C 를 고른 이유의 실물이다**: 덫이 살아 있는 바로 그 자리에서도
래퍼 층은 혼자 빨갛다. 두 층은 **같은 사고를 서로 다른 자리에서** 문다.

- **B 만 있었다면** — 첫 줄이 안 생긴다. 그러나 ③ 의 `-s scripts` 길은 초록이었다.
- **A 만 있었다면** — 둘째 줄은 나오지만 맨몸으로 간 첫 줄이 그대로 초록이었다.
  설계가 A 를 버린 이유(「그날 친 명령에 파이프도 래퍼도 없었다」)가 여기서 실측이 됐다.
