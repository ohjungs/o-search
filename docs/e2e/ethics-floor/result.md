# 결과 — 계획 81 `ethics-floor`

e2e 는 **해당 없음**이다(새 시나리오가 없다 — 기존 크롤 e2e 가 이미 간격을 실측한다).
대신 **변이로 이빨을 쟀다.** 못은 「무는가」를 보여야 값이 있고, 초록불은 그것을 못 보여준다.

## 1. 변이 3판 — 전부 물었다

| 변이 | 결과 |
|---|---|
| `DOMAIN_INTERVAL = 0.05` — **2026-09-09 실제 사고값** | **FAILED (failures=2)** |
| `DOMAIN_INTERVAL = 0.9` — 경계에서 살짝만 | **FAILED (failures=2)** |
| `set_delay` 의 `max(interval, seconds)` 제거 | **FAILED (failures=1)** |

**변이는 저장소 사본에서 쟀다.** 원본 소스를 낮춰 재면 중단이 곧 윤리 위반으로 남고,
그 중단은 예고 없이 온다 — 오늘 아침에 실제로 그렇게 됐다(`docs/e2e/recrawl/result.md` 3절).
**이 계획을 하는 도중에 나 자신이 같은 실수를 한 번 했고**, 바로 되돌린 뒤 사본으로 옮겼다.
규율은 이렇게 새고, 그래서 못이 필요하다.

## 2. 무엇이 뚫려 있었나

```diff
-DOMAIN_INTERVAL = 1.0   # 초 — concept.md 크롤 윤리, 내리지 않는다
+DOMAIN_INTERVAL = 0.05  # 초 — concept.md 크롤 윤리, 내리지 않는다
```

**전수 706건이 이 상태로 전부 초록이었다.** 잡은 것은 검사가 아니라 사람이 diff 를 본 것이다.

**기존 단언이 못 잡은 이유는 전부 상수를 «참조» 하기 때문이다** —
`assertEqual(f.interval("a.test"), DOMAIN_INTERVAL)` 는 값을 내리면 단언도 같이 내려가
언제나 참이다. 「간격을 지키나」는 재도 **「그 간격이 윤리 하한 위인가」는 아무도 안 잰다.**

## 3. 그래서 하한을 리터럴로 박았다

`SPEC_FLOOR = 1.0` 은 `docs/specs/concept.md` 기능 3 이 준 숫자다. **상수로 빼지 않는다** —
빼면 그 상수를 같이 내려서 다시 뚫린다. **재는 쪽과 재이는 쪽이 같은 값을 공유하면
그것은 자가 아니다.** 이 저장소가 여러 번 배운 모양이고, 이번엔 윤리 축에서 났다.

## 4. 둘째 단언은 고친 것이 아니라 붙든 것

`set_delay` 는 이미 `max(interval, seconds)` 로 단조 증가라 robots 가 **짧게** 요구해도
안 따른다. 그 성질이 **주석에만** 있었고, 주석은 리팩터링을 못 막는다. 변이 3판이
그것을 확인한다(`max` 를 빼면 죽는다).

## 5. 함께 잰 것 — 처리량은 코드 문제가 아니다

같은 반복에서 도메인 수만 바꿔 크롤 처리량을 쟀다(전부 로컬 루프백 · 남의 서버 안 침):

| 도메인 | 1 | 2 | 4 | 8 |
|---|---|---|---|---|
| 문서/초 | 1.03 | 2.08 | **4.40** | 9.86 |

**처리량은 도메인 수에 정비례한다.** 실물 코퍼스가 3.67/초였던 것은 시드가 4도메인이라
이론 상한 4/초의 92% 에 이미 붙어 있었기 때문이다. 컨셉 성능 2(**5문서/초**)는
**도메인 5개 이상이면 자동 충족**이라 **고칠 코드가 없다** — 시드 이야기다.

이것이 이 계획에서 처리량을 안 건드린 이유이자, **간격을 낮추는 것이 유혹이 되는 이유**다.
숫자가 안 나오면 손이 그 상수로 간다. 오늘 실제로 그랬고, 이제 못이 막는다.
