### 반복 627 — 개발 스텝 1 · **재는 자가 섰고 빨갛다** (`tests/test_verdict_wrapper.py`)

6건 중 **5건 실패**(전수 818건 `FAILED (failures=5)` `rc=1`). 실패 메시지가 「없는 파일」이

가드가 아니라 **실제로 돌리는** 자다: 계약 ③(`rc`)은 낱말을 세서는 영영 못 잰다. 여섯째는
**대조군**이라 지금 초록이어야 맞다 — 래퍼 없이 같은 파이프를 태우면 판정이 실제로 사라지는지
먼저 확인한다(안 사라지면 나머지 다섯은 「고쳐서 통과」가 아니라 **깨진 적 없는 것을 잰 것**).
**그리고 이 반복이 서른일곱 번째 표본을 냈다** — 전수를 친다면서 `discover -b`(시작 디렉터리
**누락**)를 쳐 **`Ran 0 tests / OK / rc=0`** 을 받았다. **파이프를 안 붙였는데도 0 을 세며
초록**이었다 — 조항이 못 덮는 **새 얼굴**이고, 잡아낸 것은 눈이 아니라 `project.md` 에 적힌
명령과 대 본 것이다(후보 등재). README 단위 수 가드가 812→818 로 물어 함께 맞췄다.

**같은 반복 끝에 하나 더 — 조항을 어겼는데 손실이 0 이다.** 기록을 갱신하고 전수를 다시
칠 때 `2>/tmp/vl_run.txt` 뒤에 `echo "rc=$?"` 와 `grep -E '^(Ran |OK|FAILED|FAIL: )'` 를

화면에 있었다. **계수에 넣지 않는다**(항목이 세는 것은 «가려진 횟수»다). 값은 다른 데 있다:
손이 저절로 간 모양이 **계획 106 의 래퍼와 같은 모양**이었다 — 전량을 파일로 남기고 판정만
다시 찍기. **조항이 막으려던 충동은 「판정만 보고 싶다」이고, 그 충동은 옳다.** 막아야 할
것은 충동이 아니라 충동이 손으로 갈 때 생기는 손실이고, 그래서 처방이 문장이 아니라 기제다.
