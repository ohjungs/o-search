# 설계 — `e2e-fd-leak`

**트리거**: 「3개 이상 파일에 걸침」(17파일) · 「대안이 2개 이상 갈림」(아래 2절).

## 1. 무엇을 정하나

누수 자체는 논쟁거리가 아니다 — `server_close()` 를 안 부르는 것이 원인이고 `tracemalloc`
이 할당 지점을 줬다. 갈리는 것은 **고치는 자리**다: 17개 진입점 각각인가, 공용 도우미인가.

## 2. 대안

### A. 진입점마다 한 줄 (`shutdown()` 다음에 `server_close()`)

저장소가 **이미 셋에서 그렇게 하고 있다** — `design_check.py:441-442` ·
`passage_eval.py:248-249` · `perf_search.py:109-110`. 새로 만드는 개념이 0개다.

### B. 공용 도우미 `e2e/_harness.py` 에 컨텍스트매니저를 두고 22개 진입점을 옮긴다

```python
@contextmanager
def serving(handler): ...   # yield base_url; finally shutdown + server_close
```

### C. `atexit` 훅에서 살아있는 서버를 일괄로 닫는다

## 3. 비교

| 기준 | A (진입점마다) | B (공용 도우미) | C (`atexit`) |
|---|---|---|---|
| **되돌릴 수 있나** | **파일마다 한 줄** — 되돌리기가 파일 단위다 | 22개 진입점을 한 번에 옮긴다. 되돌리면 전부 되돌아간다 | 전역 훅이라 되돌리기는 쉬우나 **무엇이 닫혔는지 안 보인다** |
| **단순한가** | 개념 0개 추가 | 새 모듈 + 새 공개 인터페이스 (설계 트리거를 또 켠다) | 암묵 · 3am 에 해독할 종류 |
| **밤에 해도 되나** | 된다 | **안 된다** — `discover.md` 3절 아키텍처 변경 금지. digest 가 「e2e 도우미 0건(22/22 진입점)」으로 등재한 열리지 않은 문이다 | 된다 |
| **원인을 고치나** | 고친다 | 고친다 | **안 고친다** — 누수를 종료 시점까지 미룰 뿐, 프로세스가 사는 동안 fd 는 그대로 쌓인다 |

## 4. 고른 것 — A

`concept.md` 의 **경량** 축과도 같은 방향이다. B 의 이점(중복 제거)은 이 저장소가 e2e 를
**독립 실행 파일**로 유지해 온 결정과 정면으로 부딪히고, 그 결정을 뒤집는 것은 밤의 몫이
아니다. C 는 증상만 옮긴다.

**B 를 영영 버리는 것이 아니다** — 도우미 게이트가 열리는 날 A 의 한 줄들은 그 컨텍스트
매니저 안으로 그대로 접힌다. A 는 B 를 막지 않는다.

## 5. 회귀를 무엇으로 잡나 — 여기가 진짜 설계 결정이다

고치는 것보다 **다시 새지 않게 하는 것**이 어렵다. 게이트 ⑫ 가 적은 그대로 「경고 축을
지키는 자가 0곳」이고, 그 자리를 여는 정공법(`project.md` 러너 명령에 `-W` 추가)은
**사용자 승인 대기**다.

| 대안 | 문제 |
|---|---|
| 단위 전수 안에서 18종 e2e 를 `-W` 로 돌린다 | **전수 안에서 전수를 다시 돌리는 모양**이다(게이트 ⑫ 가 지목한 그것). 19초짜리 스위트가 분 단위가 된다 |
| `project.md` 러너 명령에 `-W` 를 더한다 | **승인 대기**(게이트 ⑫). 밤이 저장소의 규율 문구를 혼자 안 바꾼다 |
| **소스를 입력으로 읽는 정적 가드** ← 고른 것 | 대리 측정이다 (아래 천장) |

**고른 이유**: 이 저장소에 **이미 있는 부류**다 — `test_docs.py`·`test_readme.py` 가 문서를
입력으로 읽고, digest 가 「문서를 입력으로 읽는 검사가 한 벌은 있어야 한다」로 등재해 뒀다.
승인이 필요 없고, 19초 예산을 안 건드리고, **17파일을 이름으로 지목**한다.

**천장을 적는다** — 정적 가드는 `server_close()` 라는 **낱말**을 보지 실제 fd 를 안 센다.
`server_close()` 를 부르면서 다른 소켓을 새로 흘리면 못 잡는다. 진짜 측정은 `-W always`
재측정이고 그것은 사람이 돌리는 것으로 남는다 — `project.md` 게이트가 열리는 날 승격된다.
코드에 `ponytail:` 주석으로 이 천장과 승격 경로를 적어 둔다.
