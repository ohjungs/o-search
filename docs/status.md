## 방금 한 것 (2026-09-02 · 계획 46 설계)

**탐침이 갈림길 D 의 답을 실측으로 줬다.** `indexer.search()` 를 여섯 DB 상태에 직접
걸었다(임시 디렉터리 · `data/crawl.db` 는 읽지도 않았다).

| DB 상태 | `docs` 테이블 | `search()` | 오늘 HTTP |
|---|---|---|---|
| DB 파일 없음 | — | `FileNotFoundError` | 500 |
| **크롤만 함** | **없음** | `[]` | **200** |
| **빈 DB (pages 도 없음)** | **없음** | `[]` | **200** |
| 색인 돌았고 0건 | 있음 · 0행 | `[]` | 200 |
| 정상 색인 · 무매치 | 있음 · 1행 | `[]` | 200 |
| 색인 드리프트 | 있음 · 옛 정의 | `StaleIndexError` | 500 |

- **오늘의 `200 + []` 는 네 상태를 덮는다.** 앞 둘은 "색인이 없다"이고 뒤 둘은 정상이다.
  가르는 술어는 `docs` 테이블의 **존재**이고 `indexer.search` 는 그것을 `indexer.py:183-185`
  에서 **이미 판별하고서 `[]` 로 합친다.** D 를 200 으로 닫되 이 사실을
  `TestUnindexedDb` 독스트링에 못박는다 — 안 적으면 다음 사람이 다시 연다.
- **두 번째 탐침이 계획이 못 본 구멍을 찾았다.** 오늘 `serve` 의 500 을 재는 단언은
  `FileNotFoundError` **하나**에만 붙어 있다. 드리프트를 HTTP 로 재는 단언 0건,
  프로그래밍 오류가 500 이라는 단언 0건(`test_hostile_query_strings_do_not_500` 은
  이름과 달리 **200 을 못박는** 단언이라 `except Exception` 절에 아예 안 닿는다).
  **스텝 1 이 `TestMissingDb` 를 503 으로 뒤집으면 JSON 경로의 500 커버리지가 0 이 된다** —
  계획 42~45 의 교훈 ①(*"데이터가 초록일 때 자기를 못 잰다"*)의 이번 판이다.
  **개발이 M5 단언을 먼저 심는다.**
- **기각한 안의 값도 실측했다.** A 의 `/v1/search` 안은 `/search` 직접 호출이
  **e2e 4파일 14곳**이고 그중 셋이 `serve.main` 시작 줄을 `line.split("/search")[0]` 로
  파싱해 경로를 바꾸면 통째로 깨진다 — 계획서 리스크 절이 예고한 그대로다.
- **변이 표 14줄**, 교훈 ②(*"넓어지는 변이는 잡히고 좁아지는 변이는 안 잡히는 비대칭"*)
