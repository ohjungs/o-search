# 설계: 계획 107 `zero-population` — 0건 전수는 초록이 아니다

## 결정 — **C. 둘 다 넣는다**

**둘 중 하나로는 안 된다는 것이 근거다.** 오늘 실제로 난 사고(digest 서른일곱째)는
**맨몸** 명령이었고, 사고 «부류» 는 맨몸 밖에도 있다.

1. **빈 `tests/__init__.py` 한 개** — 오늘의 덫을 뿌리에서 없앤다. 시작 디렉터리를
   빠뜨린 맨몸 전수가 0건이 아니라 **826건**을 돈다.
2. **`scripts/verdict.sh` 가 `Ran 0 tests` 를 판정이 아니라 사고로 읽는다** — 감싼
   명령이 0건을 남기고 `rc` 가 0 이면 **`rc=2`** 로 바꾼다. 이 저장소의 관용구에서
   **2 는 판정이 아니라 「재지 못했다」** 이고, 0건이 정확히 그것이다.

## 대안 비교

| | A. 래퍼만 (정공법) | B. `__init__.py` 만 (최소) | **C. 둘 다** |
|---|---|---|---|
| 되돌리기 | 쉬움(한 줄) | 쉬움(파일 1개) | 쉬움(각각 따로) |
| 코드량 | 2~3줄 | **0줄**(빈 파일) | 2~3줄 + 빈 파일 |
| 기존과 일치 | ○ `0/1/2` 관용구 | △ 무는 자가 아니다 | ○ |
| 다음이 편한가 | 보통 | 보통 | 좋음 |
| **오늘 난 사고를 막나** | **✗ 맨몸이었다** | ○ | ○ |
| **사고 부류를 막나** | ○ | **✗ 다른 0건 길은 초록** | ○ |

**선택: C** — 마지막 두 줄이 갈랐다. **A 를 버린 이유**: 그날 친 명령에 파이프도 래퍼도
없었다. 래퍼만 고치면 실제로 난 사고를 그대로 다시 낼 수 있다. **B 를 버린 이유**:
덫 하나를 치울 뿐 「0건인데 초록」이라는 판정 자체는 그대로다 — 잘못된 `-k` 필터나 빈
`-s` 대상은 내일도 `OK rc=0` 이다. 둘은 겹치지 않고 **서로의 구멍이 상대의 값**이다.

**digest 가 적어 둔 처방을 탐침이 뒤집었다.** 그 항목은 *"밖에서 세는 자리는 래퍼뿐"*
이라고 적었는데, 탐침 2 가 더 싼 자리를 찾았다 — **세는 대신 덫을 치우는 것**이다.
그래서 C 는 A 의 확장이 아니라 **A 가 놓친 자리를 B 가 메우는 것**이다.

## 가정 — 셋 다 실측으로 깼다(반복 633~634 · `git clone --local` 사본 `/tmp/zp2`)

1. **빈 `tests/__init__.py` 를 놔도 826건이 그대로 돈다** → 참. 문서화된 세 꼴 전부
   **826 OK**: 시작 디렉터리 없는 맨몸 · `discover -b tests` · `discover -b -s tests`
   (`scripts/merge-to-main.sh` 가 쓰는 꼴).
2. **`project.md` 품질 기준 표의 `-m unittest tests.test_deps` 도 그대로다** → 참.
   사본·원본 양쪽에서 **9건 OK**. (오늘도 도는 것은 암묵 네임스페이스 패키지 덕이고,
   `__init__.py` 가 생기면 정규 패키지가 되는데 **결과가 같다**.)
3. **`Ran 0 tests` 는 로그에 그 표기로 정확히 나온다** → 참. 탐침 1 실측
   `Ran 0 tests in 0.000s` · 래퍼 마지막 줄 `── Ran 0 tests in 0.000s OK rc=0`.

**틀렸으면 설계가 무너지는 것은 1번**이다 — 826 중 하나라도 깨졌으면 B 가 죽고 C 는
A 로 내려앉는다. 세 꼴 전부 초록이라 내려앉지 않는다.

## 계약 — 개발이 지킬 것

- **`tests/__init__.py`** 는 **주석만** 든다(임포트 0개). 빈 파일로 두면 다음
  사람이 「쓸모없는 파일」로 지운다 — 지우는 순간 덫이 되살아난다.
  **자기수정(반복 639 리뷰)**: 계약의 첫 판은 「한 줄 주석만」이었는데 실물은 **세 줄**이다.
  한 줄에는 「왜 있는지」만 들어가고 **어디를 읽어야 하는지**가 안 들어간다 — 지우려는
  사람에게 필요한 것이 그 포인터(설계 문서와 무는 자)라, 계약 쪽을 사실에 맞춘다.
- **`scripts/verdict.sh`** — 마지막 줄의 꼴 `── <판정들> rc=N` 을 **바꾸지 않는다.**
  바뀌는 것은 둘뿐이다: 로그에 `Ran 0 tests` 가 있고 `rc` 가 0 일 때 ① 그 줄에 낱말
  **`모집단 0`** 이 들고 ② **`rc=2`** 로 나간다(종료 코드도 2).
- **`rc` 가 0 이 아닐 때는 손대지 않는다** — 수집 단계에서 죽어 0건인 경우는 이미
  빨갛고, 덧쓰면 원래 코드를 잃는다.
- **판정 칸이 빈 것과 0건은 다르다.** e2e 스크립트는 `Ran/OK` 낱말을 안 써서 판정
  칸이 비고 `── rc=0` 만 남는다(계획 106 이 천장으로 받아들인 값) — **그대로 `rc=0`
  이어야 한다.** 조건은 「판정 칸이 비었나」가 아니라 **「`Ran 0 tests` 가 있나」** 다.

## 되돌리기

각각 따로 revert 된다 — 파일이 겹치지 않는다. `tests/__init__.py` 는 삭제,
래퍼는 조건 블록 삭제. 둘 다 되돌려도 오늘과 같은 상태이고 데이터는 안 만진다.

## 범위 밖

- **건수의 «값»** — `README.md` 의 단위 수 가드(`tests/test_readme.py`)가 이미 그 자다.
  여기는 **0 대 0 아님**만 본다.
- **0건이 나오는 나머지 길**(오타 난 `-k` · 빈 `-s` 대상 · 다른 cwd) — C 의 래퍼 쪽이
  래퍼를 통과한 것만 덮는다. 맨몸으로 그 길을 가면 여전히 초록이다. `digest` 후보로.
- `scripts/merge-to-main.sh` — 시작 디렉터리를 이미 명시한다. 0줄.
