### ③ **빨간 전수가 이 계획의 중심이다** — 여기가 진짜 사고 현장이다

`-b` 는 **통과한** 것의 출력만 삼킨다. 실패한 테스트의 stdout 은 그대로 밀려 나오므로
**빨간 날 정확히 눈이 먼다.** 초록으로만 재면 이 칸을 영영 못 본다.

`tests/test_smoke.py` 에 변이를 심어(`"0.1"` → `"0.1-변이"` + `print`) 실제로 빨갛게 만들고
**같은 손**으로 쟀다:

| | `2>&1 \| tail -3` 이 보여 준 것 | 쉘이 본 `rc` |
|---|---|---|
| **래퍼 없이** | `Stdout:` / `e2e 변이: 실패한 테스트의 stdout 은 -b 가 안 삼킨다` — **판정 0줄** | **`0`** |
| **래퍼로** | `── Ran 826 tests in 25.926s FAILED (failures=1) rc=1` | `0`(`tail` 의 것) |
| **래퍼 · 맨몸** | `── Ran 826 tests in 25.676s FAILED (failures=1) rc=1` | **`1`** |

**첫 줄이 digest 최다 항목의 실물이다** — 실패한 전수가 「아무 일도 없었다」로 보이고
**쉘까지 0 을 준다.** 둘째 줄이 처방의 값이다: 파이프가 `rc` 를 먹어도 **글자로 실어 보낸
`rc=1`** 은 남는다. 셋째 줄이 계약 3.

**원복**: `cmp -s` 로 사본과 대조하고 `git diff --quiet` 로 트리 무변까지 확인했다
(반복 628 이 공허하게 통과한 자리라 두 겹으로 본다).
