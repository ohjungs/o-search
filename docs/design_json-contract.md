## 1. 설계 탐침이 새로 잰 것

`indexer.search()` 를 여섯 DB 상태에 직접 걸었다(임시 디렉터리 · `data/crawl.db` 는 안 열었다).

| # | DB 상태 | `docs` 테이블 | `search()` | 오늘 HTTP |
|---|---|---|---|---|
| 1 | DB 파일 없음 | — | `FileNotFoundError` | 500 |
| 2 | 크롤만 함 (pages 있음) | **없음** | `[]` | **200** |
| 3 | 빈 DB (pages 도 없음) | **없음** | `[]` | **200** |
| 4 | 색인 돌았고 0건 | 있음 · 0행 · 현재 정의 | `[]` | 200 |
| 5 | 정상 색인 · 무매치 질의 | 있음 · 1행 · 현재 정의 | `[]` | 200 |
| 6 | 색인 드리프트 | 있음 · 옛 정의 | `StaleIndexError` | 500 |

**하나 — 오늘의 `200 + []` 는 네 상태(2·3·4·5)를 덮는다.** 2·3 은 "색인이 없다"이고 4·5 는
정상이다. 가르는 술어는 `docs` 테이블의 **존재**이고 `indexer.search` 는 그것을
`indexer.py:183-185` 에서 이미 판별하고서 `[]` 로 합친다 — 갈림길 D 의 재료다(4절).

**둘 — 오늘 500 을 재는 단언은 `FileNotFoundError` 하나뿐이다**(`TestMissingDb`).
드리프트(#6)를 HTTP 로 재는 단언 0건, 프로그래밍 오류가 500 이라는 단언 0건
(`test_hostile_query_strings_do_not_500` 은 이름과 달리 **200 을 못박아** `except Exception`
절에 안 닿는다). **스텝 1 이 `TestMissingDb` 를 뒤집으면 500 커버리지가 0 이 된다** — M5.

**셋 — `README.md:39`** 의 *"요청마다 500 을 낸다"* 를 스텝 1 이 거짓으로 만든다. 계획서는
README 를 스텝 2 에 걸어 뒀는데 걸리는 것은 **스텝 1** 이다(계획서 정정).

## 2. 갈림길 A — 본문 최상위 `"version": 1`, 붙이는 자리는 `_send` 하나

| 출발점 | 안 | 판정 |
|---|---|---|
| **최소** | 본문 최상위에 `"version": 1` 한 필드 | **채택** |
| **정공법** | URL 에 버전 — `/v1/search` 를 새로 연다 | 기각 |
| **되돌리기 우선** | `Content-Type: application/vnd.websearch.v1+json` | 기각 |

- **정공법 기각(실측)**: `/search` 직접 호출이 **e2e 4파일 14곳**이고 그중 셋이 `serve.main`
  시작 줄을 `line.split("/search")[0]` 로 파싱한다 — 경로를 바꾸면 통째로 깨지고 되돌리기가
  "경로 삭제"라 어렵다. **되돌리기 우선 기각**: 사양 기능 9 는 *"**응답 스키마**는 버전을
  갖는다"* — 스키마의 버전이지 전송의 버전이 아니다. 커스텀 미디어 타입은
  `test_json_content_type_with_charset` 이 못박은 값과 부딪힌다.
- **이름·타입**: 기존 최상위 키가 전부 소문자 단어라 `version` 이 그 계보고, 값은 **정수 1**
  이다 — 사양이 *"새 버전에서만"* 이라 단조 증가고 `>=` 비교가 된다. `"1"` 은 안 된다(M12).
- **자리**: 다섯 응답이 전부 `_send` 하나를 지난다 — 호출부마다 붙이면 다섯 벌이고 하나가
  빠진다. 화면은 `_send_html` 이라 *"안 붙인다"* 가 **구조로** 성립한다.

## 3. 갈림길 B·C — `except` 절 한 줄씩, **두 경로 모두** 503

| 출발점 | 안 | 판정 |
|---|---|---|
| **최소** | `except` 체인에 `(FileNotFoundError, StaleIndexError)` 절 하나 | **채택** |
| **정공법** | `indexer` 에 공통 기반 예외를 두고 serve 는 그것만 잡는다 | 기각 |
| **되돌리기 우선** | 요청 전에 `os.path.exists(db_path)` 를 먼저 본다 | 기각 |

- **정공법 기각**: `FileNotFoundError` 는 **stdlib 이라 상속 계층을 못 바꾼다.**
  `indexer.search` 가 자기 예외로 갈아끼우면 `indexer.main:240` 과 `test_indexer.py` 가 걸려
  **계획 40 `exit-code-contract` 가 닫은 CLI 계약이 다시 열린다.**
- **되돌리기 우선 기각**: 드리프트를 못 잡고, TOCTOU 를 만들고, 요청마다 syscall 이 는다.
- **`except` 가 넓지 않은가**: `try` 는 `_parse` 와 `_page_hits` 만 덮고 후자 안에서 도는 것은
  `indexer.search` 하나다. `FileNotFoundError` 는 `indexer.py:176-177` **한 자리**에서만 나고
  sqlite 연결 실패는 `sqlite3.OperationalError` 라 안 걸린다. **좁다.**
- **순서가 계약이다**: `ValueError`(400) → 새 절(503) → `Exception`(500). 새 절이
  `except Exception` **뒤**면 도달 불가다(M2).
- **C — 화면도 503.** 상태 코드를 읽는 것은 사람이 아니라 **인프라**다. 500 은 재시도 안 하는
  값, 503 은 하는 값 — 색인을 다시 돌리면 낫는 상태에 500 은 틀린 신호이고 프록시·모니터링이
  한 사고를 두 값으로 본다. 코드를 내는 자리를 함수로 뽑는 안은 기각했다: 400·500 이 이미 두
  경로에 두 벌로 나란히 있어 503 만 한 벌이면 대칭이 깨진다(YAGNI).
  **문구는 `"색인이 아직 준비되지 않았다"`** — `"검색 중 오류가 났다"` 와 할 일이 다르다.

## 4. 갈림길 D — 미색인은 **200 유지**, 열 조건만 적어 둔다

사양 디자인 5 는 *"503 = **색인이 없다**"* 라 적었지 *"결과 0건"* 이라 안 적었다.
crawl → index → serve 순서상 #2 는 **정상적으로 존재하는 창**이지 고장이 아니다.

여는 두 안이 오늘 비싸다: 정공법(`indexer.search` 가 새 예외)은 `indexer.py` 와 그 **모든**
호출부(`test_indexer.py`·`quality_eval.py`·e2e 다수)를 건드려 스텝 1 이 40줄을 넘고,
되돌리기 우선(serve 가 빈 결과일 때 `docs` 존재를 다시 본다)은 같은 판정을 두 자리에 두는
것이라 `serve.py:37` 주석(*"막는 자리가 둘이면 한쪽만 고쳐진다"*)이 금지한 패턴이다.

**200 을 유지하되 1절 표를 `TestUnindexedDb` 독스트링에 못박는다** — *"이 200 은 네 상태를
덮는다. 그것이 오늘의 결정이다."* 안 적으면 다음 사람이 다시 연다.
**열 조건**: 계획 47(근거 문단 API)이 `indexer` 를 어차피 건드릴 때 함께 본다.

## 5. 계약 — 스텝별로 무엇이 참이 되나

계획서의 3스텝 경계는 **그대로다**(순증 추정: ① 약 12줄 · ② 약 4줄 · ③ **0줄**, 셋 다 40줄
아래). 스텝 1 의 열린 자리(*"화면의 상태 코드는 갈림길 C 가 정한다"*)에 답이 채워졌고,
**계획서 정정은 한 줄** — 6절 표의 `README.md` 행을 스텝 2 → **스텝 1** 로 옮긴다.

**스텝 1 — 색인이 없으면 503.** `GET /search` 가 DB 없음(#1)·드리프트(#6)에 503 +
`application/json; charset=utf-8`. `GET /?q=…` 도 같은 두 원인에 503 + `text/html`,
문구는 *"색인이 아직 준비되지 않았다"*, 검색창은 남는다. **본문은 고정 문구다** —
`str(exc)` 는 `FileNotFoundError(db_path)` 라 **DB 경로 그 자체**이고, `TestMissingDb` ·
`TestHtmlPathFailsSafely` 의 경로 누출 단언은 503 으로 **옮겨서 살린다**. 원인은 `log_error`
로 stderr 에 남고 로그 단언도 함께 옮긴다. **프로그래밍 오류는 500 그대로이고 그것을 재는
단언이 새로 필요하다**(M5). 미색인(#2)은 200 유지 · `TestUnindexedDb` 독스트링에 4절 결정.
`README.md:39` 는 503/500 을 가르는 문장으로 고친다. **`Retry-After` 는 안 붙인다** —
색인이 언제 도는지 서버가 모른다.

**스텝 2 — 응답 스키마에 버전.** `VERSION = 1` 상수 하나, `_send` 가
`{"version": VERSION, **payload}` 로 낸다 — **200·400·404·500·503 전부**가 정수로 갖는다.
**화면에는 안 붙고**(`_send_html` 이 다른 함수) 그것을 부정 단언으로 못박는다(M11).
기존 단언과 안 부딪힌다(실측): `set(hit) == {"url","title","snippet"}` 는 **결과 항목**에
걸린 것이고 최상위 키 집합 단언은 `test_serve.py`·`search_api_e2e.py` 둘 다 0건이다.

**스텝 3 — 화면과 JSON 의 순서가 같다(사양 기능 6).** 같은 질의·같은 페이지에서 `/` HTML 의
URL 목록 == `/search` 의 `results[].url`, **순서까지 리스트로** 비교한다(집합이면 M14 를
놓친다). HTML 에서 뽑는 자리는 `<div class="url">` 이다 — **모든 hit 이 갖는다.**
링크(`<a href>`)로 뽑으면 `_safe_href` 가 거른 URL 이 빠져 길이가 달라진다. 값은
`html.escape` 를 지났으므로 `html.unescape`(stdlib)로 되돌린다. 20문서 픽스처
(`MANY_PAGES`)로 **1·2페이지 둘 다** 잰다(한 페이지면 M13 이 안 죽는다).
**제품 코드 0줄** — 두 경로는 이미 `_page_hits` 한 벌을 나눠 쓴다(`serve.py:276` 주석).

## 6. 검사가 진짜인지 재는 변이

교훈 ②(*"넓어지는 변이는 잡히고 좁아지는 변이는 안 잡히는 비대칭"*)대로 **좁히는 변이를
절반** 넣었다. `오늘` 이 "0건"이면 그 단언을 **새로 만들어야 한다**는 뜻이다.

| # | 방향 | 변이 | 죽어야 하는 단언 | 오늘 |
|---|---|---|---|---|
| M1 | — | 503 절을 통째로 삭제 | `TestMissingDb` 503 · 화면 503 | 새로 |
| M2 | — | 503 절을 `except Exception` **뒤로** | 같음 (순서가 계약이다) | 새로 |
| M3 | **좁힘** | 튜플에서 `StaleIndexError` 만 뺀다 | **드리프트 → 503** | **0건 — 픽스처부터** |
| M4 | **좁힘** | 튜플에서 `FileNotFoundError` 만 뺀다 | `TestMissingDb` 503 | 새로 |
| M5 | **넓힘** | `except Exception` 을 503 으로 | **프로그래밍 오류 → 500** | **0건** (1절 둘) |
| M6 | **좁힘** | `_do_html` 쪽 503 절만 삭제 | 화면 503 (갈림길 C) | 새로 |
| M7 | **좁힘** | 503 을 `_send_html` 로 낸다 | 503 의 JSON `Content-Type` | 새로 |
| M8 | — | `_send` 에서 `"version"` 삭제 | 200·오류 양쪽의 버전 | 새로 |
| M9 | **좁힘** | 200 호출부에만 버전을 붙인다 | **오류 응답**의 버전 (A 의 "한 곳") | 새로 |
| M10 | — | `VERSION = 1` → `2` | 값을 못박은 단언 | 새로 |
| M11 | **넓힘** | `_send_html` 에도 버전을 붙인다 | **HTML 엔 버전이 없다**는 부정 단언 | **0건** |
| M12 | **좁힘** | `version` 값을 `"1"`(문자열)로 | 타입까지 본 `assertEqual(…, 1)` | 새로 |
| M13 | — | `_do_html` 의 `_page_hits` 에 `page + 1` | 화면↔JSON URL **리스트** 동등 | 새로 |
| M14 | **좁힘** | 화면 쪽 `hits` 만 `reversed()` | 같음 — **집합 비교면 안 죽는다** | 새로 |

**M3·M5·M11 이 핵심이다.** 셋 다 오늘 재는 것이 0건이고, 앞의 둘은 스텝 1 이 `TestMissingDb`
를 뒤집으며 **500 을 재는 단언을 0건으로 만드는** 자리다 — 교훈 ①(*"데이터가 초록일 때 자기를
못 잰다"*)의 이번 판이다. 새 503 이 초록이라 사라진 500 커버리지가 안 보인다.

**절차**: 변이를 심는 동안 `.mutation-lock` 을 두고 각 변이는 **되돌린 뒤 초록을 눈으로**
확인한다. 러너는 맨몸이다 — `PYTHONPATH=src python3 -m unittest discover -s tests`
(`project.md ## 명령`. 파이프·`tail` 금지).

## 7. 성능 계약 (사양 성능 4 — JSON p95 ≤ 300ms)

**새 스크립트를 안 만든다.** `e2e/perf_search.py` 가 이미 `BUDGET_MS = 300` 으로 `GET /search`
의 p50·p95 를 재고 예산 초과에 assert 로 죽는다(`perf_search.py:121-123`).

- **측정**: e2e phase 가 `PYTHONPATH=src python3 e2e/perf_search.py` 를 맨몸으로 한 번.
- **판정 ①(자동)** p95 ≥ 300ms → RED. **판정 ②(눈)** `project.md` 기준선(2026-08-27 /
  3000문서 / p95 **9.11ms**)의 **2배를 넘으면 설계가 틀린 것**이라 리뷰로 되돌린다.
  스크립트가 이 축을 안 재므로 e2e 문서에 숫자를 적어 비교한다.
- **왜 안 늘어야 하나**: 질의 경로(`_page_hits`·`indexer.search`)가 **무수정**이고 느는 것은
  본문의 `"version":1` 약 14바이트뿐이다(`json.dumps` 는 이미 도는 자리). 503 절은 정상
  요청에서 안 밟힌다.

## 8. 되돌리기 · 보안 · 범위 밖

**되돌리기**: `rules/design.md` 3절 ③ **커밋 하나로 revert**. 피처 플래그 불필요 — 새 경로·
파일·의존성 0 이고 저장 형태 무변경 · `data/crawl.db` 무변경이라 **마이그레이션 단계 자체가
없다**. **보안(CSO)**: 신뢰 경계는 그대로고 새로 생기는 유일한 유출 경로는 **503 본문의
`str(exc)`(= DB 경로)** 인데 5절이 고정 문구로 못박고 경로 누출 단언으로 지킨다.

**범위 밖** (일부러 안 한다 — 교훈 ③대로 사유를 적는다):

- **M15 `ORDER BY` 변이** — 두 경로가 같이 움직여 안 죽는다. 스텝 3 이 재는 것은 *"두 경로의
  일치"*지 *"랭킹의 옳음"*이 아니다. 랭킹은 `e2e/quality_eval.py` 몫이다.
  **M16 탐침 행 누출** — `test_count_does_not_leak_the_probe_row` 가 이미 잡는다.
- **`Retry-After`** — 서버가 모르는 숫자다. **버전 협상(`Accept`·다중 버전)** — 소비자 0명,
  버전 1개. 두 번째가 실제로 필요할 때가 열 때다(ponytail 1번).
- **`has_next` 를 `truncated` 로 쪼개기** — 버전이 길을 **열지만 열지는 않는다**(사용자 확인).
- **넓은 `except Exception` 재조사** — 2026-08-29 야간에 쟀고 무죄였다. 이 설계는 그 앞에 절을
  하나 **더할** 뿐이다. **갈림길 D** — 4절, 열 조건은 계획 47.

## 9. 설계가 틀렸다면 어디서 드러나나

- **스텝 1 이 40줄을 넘으면** 갈림길 C 가 비싼 것이다. C 를 최소안(JSON 만)으로 내리고 화면은
  계획 47 로 미룬다 — 사양 디자인 5 는 API 만 말하므로 그 후퇴가 사양을 안 어긴다.
