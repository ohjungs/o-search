## 2. 이번 e2e 가 답한 것 — **README 의 명령 형태를 아무도 안 재고 있었다**

계획은 `exists`↔`connect` 창을 닫았고, 리뷰가 그 수정이 새로 연 구멍(빈 `db_path`)을
닫았다. **그 둘을 재는 단언은 단위 여섯·e2e 두 곳 모두 `tempfile` 의 절대 경로**였다.
그런데 `README.md` 의 세 명령은 전부 **상대 경로 `data/crawl.db`** 이고, 배포가
`DB_PATH` 를 안 채우면 **빈 문자열**이다. 프로세스 경계가 새로 재는 것은 정확히 이 둘 —
경로가 **argv 를 지나 cwd 위에서 해석되는 자리**다.

| # | 시나리오 | 어디서 | 실측 |
|---|---|---|---|
| 1 | README 형태 상대 경로로 색인·질의 | `indexer_e2e.py` ⑤ | `python3 -m websearch.indexer data/crawl.db --query 김치` **rc 0** · 정답 URL |
| 2 | 없는 상대 경로 | `indexer_e2e.py` ⑤ | **rc 1** · `DB 파일이 없다: data/none.db` · **빈 DB 파일 생성 0** |
| 3 | README 형태로 띄운 서버 | `search_api_e2e.py` 전체 | 서버를 `cwd=tmp` 에서 `data/crawl.db` 로 띄웠다 — ①~⑥ 이 **통째로 그 형태 위에서** 돈다(200 · 400 · 404 · 501 · 치우면 **503** · 되돌리면 200 · `version` 1) |
| 4 | 빈 `DB_PATH` 로 뜬 서버 | `search_api_e2e.py` ⑦ | `python3 -m websearch.serve "" --port 0` → **503**(가드가 없으면 200) |
| 5 | **대조군** | 아래 3절 | 변이 둘 전부 **RED** |

**3 을 «한 줄 더» 가 아니라 «형태를 바꿔서» 했다.** 절대 경로 서버를 두고 상대 경로
서버를 하나 더 띄우면 프로세스가 하나 늘고 재는 것은 같다 — 절대 경로는 단위 506건이
이미 전수로 밟는다. 상대 경로는 **아무도 안 밟던 형태**라 그쪽으로 옮기는 것이 옳다
(ponytail — 더 짧은 diff 가 더 많이 잰다).

## 3. 대조군 — 제자리 변이 둘, 전부 죽었다 (`.mutation-lock`)

| 변이 | 제품에 심은 것 | 판정 |
|---|---|---|
| **R1** | `_connect` 의 `"file:"` → `"file://"` | `indexer_e2e` rc 1 (`CLI stderr: DB 를 열 수 없다: data/crawl.db — invalid uri authority: data`) · `search_api_e2e` rc 1 (**`q=김치 → 500`**) · 단위 **1건** 사망 |
| **G1** | `_connect` 의 빈 경로 가드 → `if False:` | `search_api_e2e` rc 1 — `빈 DB 경로인데 200 다 (기대 503)` · 본문 `{"version": 1, …, "results": []}` |

**R1 이 이 반복의 값이다.** 절대 경로는 `file:///tmp/…` 라 멀쩡히 돌고 상대 경로만
`data` 를 authority 로 읽어 죽는다. 테스트 phase 가 단위 1건으로 그 축을 열었고
(`test_a_relative_db_path_still_opens`), **e2e 는 그 축이 사용자 눈에 어떻게 보이는지**를
잰다: 단위는 `OperationalError` 를 보고, e2e 는 **README 명령의 rc 1** 과 **서버의 500**
을 본다. 계약으로 치면 «색인이 없다(503)» 도 «있다(200)» 도 아닌 세 번째 답이다.

**G1 은 리뷰가 남긴 숙제 그대로다** — *"빈 `DB_PATH` 를 프로세스 경계에서 재는 자리가
아직 0개다"*(`history_current.md` 리뷰 항목 마지막 줄). 이제 1개다.

되돌림은 **초록이 아니라 `git diff -- src/`(0줄)** 로 확인했고, 되돌린 뒤 같은 e2e 를
