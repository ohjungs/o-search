## 무엇을 찾았나 — 셋은 거짓 초록, 하나는 오탐

개발 1 이 어제 세운 조건 5(셀렉터 극성)는 **조건이 옳고 읽는 폭이 좁았다.**
`NOT_RE = r":not\([^()]*\)"` 가 괄호 중첩 0겹·소문자 전용이라 넷이 샜다.

| 셀렉터 | 무엇인가 | 고치기 전 |
|---|---|---|
| ⓔ `:not(:is(:focus-visible))` | ⓒ 를 괄호 한 겹으로 감싼 것 | **거짓 초록** |
| ⓕ `:has(:focus-visible)` | 링이 조상 상자로 간다 — ⓓ 와 같은 고장 | **거짓 초록** |
| ⓖ `:NOT(:focus-visible)` | CSS 는 셀렉터 이름의 대소문자를 안 가린다 | **거짓 초록** |
| `:FOCUS-VISIBLE` | 정상 CSS 인데 소문자로만 읽었다 | **오탐(종료 2)** |

수리는 세 줄이다 — `INDIRECT_RE` 가 `:not(…)`·`:has(…)` 를 **한 겹 중첩까지·대소문자
무관**하게 지우고, `FOCUS_RE` 도 `re.I` 가 된다.
**`:is()`·`:where()` 는 안 지운다** — 투명해서 그 안의 포커스는 여전히 이 요소가 받는다.
그래서 「괄호가 보이면 지운다」로 안 넓혔고, 그 선을 **새 오탐 표**가 붙든다
(`test_transparent_pseudo_classes_still_draw_the_ring`, 단위 +1).
