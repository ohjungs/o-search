## 스텝 1 이 잡은 함정

`indexer` 의 「뒤늦게 noindex 를 선언한 문서를 뺀다」 경로가 `WHERE p.html LIKE
'%robots%'` 로 후보를 골랐는데, **압축분은 BLOB 이라 매치가 영영 0** 이다 — 예외도
빨간불도 없이 **크롤 윤리 축이 초록불 아래서 죽는** 모양이었다. **잡은 것은 픽스처가
제품 경로(`Store.upsert`)를 지났기 때문**이고, 같은 이유로 `e2e/noindex_e2e.py` 의
raw SQL 픽스처도 제품 경로로 바꿨다. digest `[7]` 로 일반화해 등재했고 `src/` 잔여는 0건.
