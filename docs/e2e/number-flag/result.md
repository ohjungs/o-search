## 왜 새 e2e 파일을 안 만들었나

이 계획이 바꾼 것은 **CLI 인자 한 줄이 어떻게 읽히는가**뿐이고, 그것을 진짜 argv 로
때리는 e2e 는 이미 있다 — `e2e/deadline_e2e.py:156` 이 `--deadline=N`·`--workers=8`(붙임)
과 `--max N`(띄움)을 섞어 준다. **새 파일은 그것을 두 번째로 셀 뿐이다**(ponytail 1번).
단위가 구조적으로 못 보는 자리는 **"거절한 뒤 진짜로 아무 서버도 안 뜬다"** 하나이고,
그것은 셸에서 포트를 직접 두드리는 쪽이 정확하다(아래 시나리오 3).
