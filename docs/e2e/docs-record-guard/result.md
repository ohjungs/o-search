## 이번 e2e 가 답한 질문

이 계획은 제품 기능이 아니라 **저장소 자신의 기록 규율**을 고쳤다. 그래서 e2e 질문이
"사용자 흐름이 도나" 가 아니라 **"진짜 절차가 이 가드를 통과하는가"** 다. 단위 검사는
*오늘의 파일*을 재고, e2e 는 *내일 사람이 밟을 절차*를 밟아 본다.

절차는 셋이다 — **회전** · **반복 기록** · **계획 완료**. 셋 다 실제로 밟았다.

## 새 `e2e/*.py` 를 왜 0개로 두는가

위 다섯 절차는 *사람이 밟는 순서*이지 프로그램이 아니다. 스크립트로 굳히면 회전 절차의
